# Haiwell Happy: `.gpc`, только LD

Haiwell — отдельная среда программирования контроллеров, и её проект нельзя мешать с Machine Expert: другой
вендор, другой формат, другой язык (у Haiwell только LD — релейные схемы). Поэтому это отдельный инструмент, а
не набор команд внутри `plc-kit`.

## Когда применять

- «Что это за `.gpc`», «наш ли это проект Haiwell» — `hawell_info` читает заголовок и говорит состояние.
- «Можно ли вытащить схему из проекта Haiwell» — сейчас нет; `hawell_check` скажет это прямо, а не заставит
  гадать по пустому ответу.
- «Сохрани программу в Haiwell» — `hawell_export` откажет с причиной. Это честный отказ: записать похожий файл
  и отдать его инженеру дороже, чем не записать ничего.

## Как запускать

Синхронизатор поднимает сервер сам (`sysai-agent mcp haiwell-happy`); вручную — `python server.py`, построчный
JSON-RPC 2.0 в stdin/stdout. Доступы к папкам проверяет SYSAI до вызова.

## Что известно о формате

Всё ниже — с настоящего проекта `600_S1_Благовещенск_01A1_071223.gpc`, 51 942 байта:

| Что | Значение |
|---|---|
| Заголовок | `b0 b0` + строка `HaiWell`, дальше двоичный заголовок |
| Язык | только LD (релейные схемы) |
| zlib-потоки | нет ни одного — это не «заархивированный проект» |
| Энтропия тела | 7,06 бит на байт — плотные данные, не текст |
| Побайтовый XOR | не снимается: ни один из 256 ключей не даёт текста |

Тело повторяет короткие последовательности с общим хвостом. Два правдоподобных объяснения — свой шифр или своё
сжатие со словарём; пока не снято ни то, ни другое. Поэтому `decoded: false`.

## Ошибки

- **`это не файл Haiwell Happy`** — нет заголовка `b0 b0 HaiWell`; возможно, это `.gpc` другой программы или
  файл повреждён.
- **`файл слишком мал для проекта`** — меньше 1 КБ: скорее всего, скачался огрызок.
- **`формат .gpc не разобран`** — это не сбой: запись невозможна, пока не снято тело. Не пытайтесь обойти
  подменой формата — потеряется работа инженера.
- **`нет файла: …`** — не выданы доступы к папке либо путь с другой машины: инструмент работает на ПК инженера.

## Чего не делать

Не выдавать `.gpc` за прочитанный проект и не собирать «похожий» файл: Haiwell откроет его как пустой проект или
откажется, а инженер узнает об этом позже. Пока формат не снят — работа с Haiwell только в самой Haiwell Happy.
