# Правила для агентов в этом репозитории

Читают все: Shogo, Codex, Claude Code, Cursor, Hermes и люди.

## Таск-бар — обязательно

1. **Перед работой открой [TASKBAR.md](TASKBAR.md).** Бери задачу оттуда. Новую работу сначала впиши туда строкой.
2. **Взял задачу** → поставь `[~] <кто>, <дата>`, перенеси в «В работе», закоммить и **запушь сразу** — так другие
   видят, что она занята. Задачу с `[~]` другого агента не трогай.
3. **Закончил задачу** → `[x]`, перенеси в «Готово» с хешем коммита, добавь строку в
   `docs/opo/plan-2026-11/STATUS.md` (что сделано и как проверено), **push сразу**. Одна задача — один push:
   прогресс не должен жить только в рабочей копии.
4. **Застрял** → `[!]` в «Заблокировано» и что именно нужно (доступ, оборудование, решение человека).
5. Одна задача «в работе» на агента.

## Готово = проверено

- Тесты: `python3 -m pytest -q tests` (окно агента: `cd agents/desktop && node --test test/unit.test.js`).
- Исправление бага — с регрессионным тестом, который без исправления падает.
- Меняешь инструмент хаба (`hub/seed/*`) — подними `version` в `TOOL.md`, в `server.py` и в тестах
  (`tests/test_net_hub.py`, `tests/test_hub_seed_*.py`), иначе агенты на ПК не получат изменение.
- Файлы EasyBuilder проверяй в настоящем EasyBuilder: `scripts/ebpro_wine.sh open <файл>` → `OPENED "…"`.

## Git

- Ветка `main`, коммиты по-английски в стиле `fix(scope): …` / `feat(scope): …`, тело — что и как проверено.
- Не коммить `dist/`, `.tmp/`, реальные проекты заказчиков и секреты.
