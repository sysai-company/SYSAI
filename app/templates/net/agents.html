Установить агента на компьютер

Один файл, двойной щелчок — и на рабочем столе появляется «Агент SYSAI». Консольных окон нет: установщик открывает своё окно и показывает шаги.

{% if agents %}Открыть карточку →{% endif %}
  1. Скачайте установщикв карточке агента — код подключения уже вложен в файл
  2. Запустите двойным щелчкомокно покажет ход работы; закрывать не нужно, это несколько минут
  3. Готовоярлык на рабочем столе, синхронизация включается при входе в Windows
